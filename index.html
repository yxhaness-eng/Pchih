Где взять ключи

1. Firebase Config JSON

1. Откройте console.firebase.google.com и создайте проект.

2. В меню слева: Build → Firestore Database (создайте базу) и Authentication → Sign-in method → Anonymous (включите).

3. Нажмите на шестерёнку Project Settings вверху слева → пролистайте вниз до Your apps → нажмите иконку </> (Web) → зарегистрируйте приложение.

4. Скопируйте объект firebaseConfig и оберните ключи в двойные кавычки (валидный JSON).

2. TMDB API Key (бесплатно)

1. Зайдите на themoviedb.org → Настройки профиля → API.

2. Запросите ключ Developer и скопируйте API Key (v3 auth).
